# Инструкции для AI-агентов

Этот репозиторий — Obsidian Vault для университета. Главная цель: поддерживать чистую, стабильную и красивую систему учебных заметок, дедлайнов, MOC-страниц, шаблонов и расписания.

Если ты AI-агент и получил ссылку на этот репозиторий, начни отсюда.

## Быстрый порядок работы

1. Прочитай:
   - `README.md`
   - `docs/AI_CONTEXT.md`
   - `docs/ARCHITECTURE.md`
   - `docs/STYLE_GUIDE.md`
   - `docs/QUALITY_CHECKLIST.md`
2. Не меняй обычные учебные заметки без прямой просьбы пользователя.
3. Для функциональных страниц используй единый CSS-класс:

```yaml
cssclasses:
  - university-dashboard
```

4. После изменений обязательно запусти проверки:

```bash
python 50-Система/Скрипты/vault-health-check.py
python -m py_compile sirius-update.py 50-Система/Скрипты/vault-health-check.py
node --check .obsidian/plugins/sirius-schedule/main.js
```

5. Если менял DataviewJS-блоки, проверь синтаксис JS. Пример команды:

```bash
python docs/check-dataviewjs-syntax.py
```

Если этого скрипта нет или он не запускается — временно извлеки `dataviewjs` блоки и проверь через `node --check`.

## Что нельзя делать без разрешения

- Удалять содержательные учебные заметки.
- Менять личные заметки в `30-Личное`, кроме системных страниц `MOC`/`Личное.md`.
- Коммитить реальные пароли, токены, API-ключи, email/логины.
- Ломать frontmatter `due_date`, `status`, `subject`, `type`.
- Массово переименовывать файлы без обновления ссылок.
- Заменять DataviewJS на статические списки, если не попросили.
- Добавлять внешние CDN/картинки в страницы, если можно сделать локально через CSS.

## Архитектурные принципы

### 1. Функциональные страницы динамические

MOC, дашборды и индексы должны собирать данные через DataviewJS, а не хранить длинные ручные списки ссылок.

### 2. Дизайн централизован

Единая дизайн-система находится здесь:

```text
.obsidian/snippets/university-dashboard-v5.css
```

Не размазывай inline-стили по DataviewJS, если можно добавить класс в CSS.

### 3. Дедлайны строятся по `due_date`

Задача попадает в дашборд дедлайнов, если во frontmatter есть:

```yaml
due_date: 2026-06-01
status: В работе
```

Статус `Готово` считается выполненным.

### 4. MOC должны быть однотипными

Предметные MOC используют один шаблон:

```text
10-Университет/<Предмет>/MOC — <Предмет>.md
```

Они группируют материалы по `type` и показывают статусы/сроки.

### 5. Проверка важнее красоты

Любое улучшение должно сохранять:

- валидный Markdown;
- валидный DataviewJS;
- отсутствие битых ссылок;
- отсутствие пустых файлов;
- отсутствие секретов.

## Минимальный Definition of Done

Работа считается завершённой, если:

- `python 50-Система/Скрипты/vault-health-check.py` не показывает новых проблем;
- все изменённые DataviewJS-блоки синтаксически валидны;
- `README.md` или `docs/*` обновлены, если поменялась логика;
- пользователь получил краткий отчёт: что изменено, что проверено, что проверить вручную в Obsidian.
