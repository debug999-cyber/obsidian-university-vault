# 🔄 Шаги пользователя (User Flow)

> [!doc-card] Документ проекта
> **Раздел:** ПИД / аналитические материалы
> **Файл:** 04_user_flow.md
> **Назначение:** Пошаговые сценарии и переходы между состояниями интерфейса.

> **SmurfGram — Детальные сценарии использования**

---

## 📱 Сценарий 1: Регистрация нового пользователя

### Шаг 1.1: Попадание на Landing Page

**Действия пользователя:**
1. Переходит по реферальной ссылке / рекламе / поиску
2. Видит главную страницу SmurfGram
3. Читает основные преимущества:
   - "Не блокируется РКН"
   - "Без телефона — полная анонимность"
   - "7 дней бесплатно"

**Системные действия:**
- Загрузка страницы < 2 сек
- Отслеживание UTM меток
- Установка cookies для аналитики

> [!tip] Переход
> Клик по кнопке **"Начать бесплатно"** или **"Регистрация"** → Шаг 1.2

---

### Шаг 1.2: Заполнение формы регистрации

**Действия пользователя:**
1. Вводит ключ доступа (уникальный идентификатор)
   - Минимум 8 символов
   - Латиница, цифры, спецсимволы
   - Пример: `alex_secure_2024`
2. Вводит пароль
   - Минимум 8 символов
   - Индикатор сложности пароля
3. Подтверждает пароль
4. Вводит никнейм
   - Проверка уникальности в реальном времени
   - Пример: `@alex_smurf`
5. [Опционально] Загружает аватар
6. Соглашается с условиями использования
7. Нажимает **"Создать аккаунт"**

**Валидация на лету:**
- [x] Проверка уникальности ключа (AJAX)
- [x] Проверка уникальности никнейма
- [x] Валидация сложности пароля
- [x] Совпадение паролей

> [!tip] Переход
> - Успех → Шаг 1.3
> - Ошибка → Показать конкретное сообщение, остаться на форме

---

### Шаг 1.3: Подтверждение и сохранение ключа

**Действия пользователя:**
1. Видит экран подтверждения:
   - "Ваш аккаунт создан!"
   - Отображение ключа крупным шрифтом
   - Предупреждение: "Сохраните ключ, он не восстанавливается!"
2. Копирует ключ в буфер обмена (кнопка "Копировать")
3. Сохраняет ключ в надёжное место:
   - Менеджер паролей (Bitwarden, 1Password)
   - Зашифрованная заметка
   - Физическая копия
4. Ставит галочку "Я сохранил ключ в надёжном месте"
5. Нажимает "Перейти в мессенджер"

> [!tip] Переход
> Первый вход в систему → Шаг 1.4

---

### Шаг 1.4: Первый вход (Onboarding)

**Действия пользователя:**
1. Видит приветственный экран
2. [Текущая версия] Видит пустой интерфейс:
   - Список чатов (пусто)
   - Кнопка "Новый чат"
   - Меню настроек
3. [В планах] Проходит интерактивный туториал:
   - "Нажмите здесь, чтобы найти контакты"
   - "Создайте свой первый чат"
   - "Отправьте тестовое сообщение"
4. Настраивает профиль (опционально):
   - Меняет аватар
   - Редактирует никнейм

> [!tip] Переход
> Готов к использованию → Сценарий 2 (Поиск контактов)

---

## 🔍 Сценарий 2: Поиск и добавление контакта

### Шаг 2.1: Открытие поиска

**Действия пользователя:**
1. Нажимает кнопку "Новый чат" или значок поиска
2. Открывается модальное окно / экран поиска

**Интерфейс:**
- Поле ввода с плейсхолдером "Введите никнейм..."
- Иконка поиска
- [В планах] QR сканер для быстрого добавления

---

### Шаг 2.2: Ввод никнейма

**Действия пользователя:**
1. Вводит никнейм собеседника (например: `maria_biz`)
2. Видит результаты поиска в реальном времени:
   - Аватар пользователя
   - Никнейм: @maria_biz
   - Статус: "В сети" / "Был(а) 5 минут назад"
   - Кнопка "Написать"
3. Если пользователь не найден:
   - Сообщение: "Пользователь не найден. Проверьте никнейм"
   - Предложение: "Пригласить друга в SmurfGram"

> [!tip] Переход
> Нажимает "Написать" → Шаг 2.3

---

### Шаг 2.3: Начало диалога

**Действия пользователя:**
1. Открывается чат с выбранным пользователем
2. Видит:
   - Имя собеседника в шапке
   - Статус собеседника
   - Пустое поле сообщений
   - Поле ввода сообщения внизу
3. Отправляет первое сообщение:
   - Печатает текст
   - Нажимает Enter или кнопку отправки
   - Видит отправленное сообщение в чате
   - Статус: "Отправлено" → "Доставлено" → "Прочитано"

> [!tip] Переход
> Активное общение → Сценарий 3 (Обмен сообщениями)

---

## 💬 Сценарий 3: Обмен сообщениями

### Шаг 3.1: Отправка текстового сообщения

**Действия пользователя:**
1. Печатает текст в поле ввода
2. Видит индикатор "печатает..." у собеседника (если он в чате)
3. Нажимает Enter (или Shift+Enter для новой строки)
4. Сообщение появляется в чате

**Статусы сообщения:**
| Статус | Иконка | Значение |
|--------|--------|----------|
| Отправлено | ⏱️ Одна галочка | Отправлено на сервер |
| Доставлено | ✓✓ Две галочки | Доставлено собеседнику |
| Прочитано | ✓✓ (синие) | Прочитано |

---

### Шаг 3.2: Отправка голосового сообщения

**Действия пользователя:**
1. Нажимает и удерживает кнопку микрофона
2. Видит визуализацию записи (waveform)
3. Говорит сообщение
4. Отпускает кнопку — запись завершена
5. [Опционально] Прослушивает перед отправкой
6. Нажимает "Отправить" или "Отмена"

**Альтернативный сценарий:**
- Свайп влево во время записи — отмена
- Блокировка записи (слайд вверх) — запись без удержания

---

### Шаг 3.3: Отправка файла

**Действия пользователя:**
1. Нажимает кнопку скрепки / "+"
2. Выбирает "Файл" из меню
3. [Вариант A] Перетаскивает файл в чат (drag & drop)
4. [Вариант B] Выбирает файл через диалог выбора
5. Видит превью файла (для изображений) или иконку
6. Нажимает "Отправить"

**Ограничения:**
- Максимальный размер: 50 МБ
- Допустимые форматы: все, кроме исполняемых (.exe, .bat)

**Обработка ошибок:**
- "Файл слишком большой (макс. 50 МБ)"
- "Недопустимый формат файла"
- "Ошибка загрузки, попробуйте снова"

---

## 👥 Сценарий 4: Создание и управление группой

### Шаг 4.1: Создание группы

**Действия пользователя:**
1. Нажимает "Новый чат" → "Создать группу"
2. Вводит название группы (например: "Проект Альфа")
3. [Опционально] Загружает аватар группы
4. Добавляет участников по никнеймам
5. Нажимает "Создать"

**Результат:**
- Группа создана
- Создатель автоматически становится админом
- Участники получают уведомление о добавлении

---

### Шаг 4.2: Управление группой (для администратора)

**Действия пользователя:**
1. Открывает информацию о группе (клик по названию)
2. Видит список участников
3. Может выполнить действия:
   - Добавить новых участников
   - Исключить участника
   - Назначить администратора
   - Изменить название/аватар
   - Удалить группу

---

## 💳 Сценарий 5: Покупка подписки

### Шаг 5.1: Уведомление об окончании триала

**Триггер:** За 2 дня до окончания 7 дневного триала

**Действия системы:**
1. Отправляет push уведомление:
   > "Ваш пробный период заканчивается через 2 дня. Оформите подписку!"
2. Показывает баннер в приложении
3. Отправляет email напоминание (если email указан)

> [!tip] Переход
> Пользователь кликает → Шаг 5.2

---

### Шаг 5.2: Выбор тарифа

**Действия пользователя:**
1. Открывает экран выбора подписки
2. Видит варианты:

| Период | Цена | Экономия |
|--------|------|----------|
| 1 месяц | 299 ₽ | — |
| 6 месяцев | 1 499 ₽ | 15% |
| 12 месяцев | 2 499 ₽ | 30% |

3. Выбирает подходящий тариф
4. [Опционально] Включает автопродление

> [!tip] Переход
> Нажимает "Продолжить" → Шаг 5.3

---

### Шаг 5.3: Оплата

**Действия пользователя:**
1. Вводит данные карты или выбирает сохранённую
2. Подтверждает оплату (3D Secure если требуется)
3. Ждёт обработки платежа (2–5 секунд)

**Результаты:**

> [!success] Успех
> - Показывается экран "Подписка оформлена!"
> - Отправляется email с чеком
> - Подписка активируется мгновенно
> - Пользователь возвращается в чаты

> [!danger] Ошибка
> - Показывается конкретная ошибка (недостаточно средств и т.д.)
> - Предлагается попробовать другую карту
> - Предлагается связаться с поддержкой

---

## ⚙️ Сценарий 6: Управление аккаунтом

### Шаг 6.1: Изменение профиля

**Действия пользователя:**
1. Открывает меню → "Настройки" → "Профиль"
2. Может изменить:
   - Аватар (загрузка нового / удаление)
   - Никнейм (с проверкой уникальности)
3. Сохраняет изменения

---

### Шаг 6.2: Смена пароля

**Действия пользователя:**
1. "Настройки" → "Безопасность" → "Сменить пароль"
2. Вводит текущий пароль
3. Вводит новый пароль (дважды)
4. Нажимает "Сохранить"

**Результат:**
- Пароль изменён
- Все сессии завершены (опционально)
- Отправляется email уведомление

---

### Шаг 6.3: Выход из аккаунта

**Действия пользователя:**
1. "Настройки" → "Выйти"
2. Подтверждает выход

**Результат:**
- Сессия завершена
- Пользователь перенаправлен на страницу входа
- Локальные данные очищены (кроме сохранённого ключа, если есть)

---
