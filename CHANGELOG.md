## v1.1.0 — Global theme toggle and repository cleanup

### Добавлено
- плавное переключение **всей темы Obsidian** из кнопки на `Home.md`
- временный global transition-класс для мягкой смены цветов интерфейса
- файл `VERSION` с текущей версией проекта
- правила `.gitignore` для временных, резервных и sidecar-файлов

### Изменено
- переключатель темы на `Home.md` теперь синхронизируется с реальной темой Obsidian, а не только с локальной темой dashboard
- документация обновлена под текущую точку входа: `docs/01-START-HERE.md` → `Home.md`
- `docs/04-DASHBOARDS-AND-STYLES.md` описывает глобальное переключение темы

### Очищено
- удалены macOS sidecar-файлы `._*`
- удалены пустые placeholder-файлы (`.md`, `Vault.md`, `2026-05-25.md`)
- удалены пустые `Untitled*` в корне и учебных папках
- удалены пустые `Без названия.md` в разделах проектов и личного
- удалены дубли старого шаблона `Untitled 3–5.md`
- удалён старый черновой dashboard `Home-auto-moc.md`
- удалён резервный файл `.obsidian/plugins/sirius-schedule/main.js.backup`
