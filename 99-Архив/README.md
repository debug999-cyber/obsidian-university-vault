# 99-Архив

> [!doc-card] Архив проекта
> **Что это:** место для устаревших, промежуточных и неактуальных файлов.
> **Зачем нужно:** не засорять основной vault, но не терять историю проекта.

## Что лежит в архиве

| Папка | Содержимое |
|---|---|
| `99-Архив/Legacy/Черновики/` | случайные или временные заметки |
| `99-Архив/Legacy/Старые-версии/` | старые версии шаблонов и черновиков |
| `99-Архив/Legacy/Исходные-txt/` | исходные `.txt`-материалы, заменённые `.md`-версиями |

## Что уже почищено

Из активной части vault убраны:
- пустые `Untitled*` заметки;
- пустые `Без названия`;
- старые черновики шаблонов;
- старый `Home-auto-moc.md`;
- macOS sidecar-файлы вида `._*`.

## Правило

В `99-Архив` можно складывать всё, что:
- больше не участвует в работе системы;
- не должно мешать новичку;
- но потенциально полезно как история изменений.
