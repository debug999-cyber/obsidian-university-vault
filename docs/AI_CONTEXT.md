# AI Context: Obsidian University Vault

Этот документ нужен, чтобы новая ИИ могла быстро понять проект по ссылке на GitHub.

## Назначение проекта

Vault превращает Obsidian в учебную систему:

- рабочий стол студента;
- дедлайны;
- предметные MOC;
- шаблон создания заметок;
- проектный и личный разделы;
- расписание Sirius University;
- единый дизайн функциональных страниц.

## Язык проекта

Основной язык интерфейса и документации — русский.

Код может содержать русские переменные в DataviewJS, но предпочтительно для новых блоков использовать понятные английские имена (`root`, `pages`, `renderCard`) и русские тексты UI.

## Основные пользовательские сценарии

### 1. Открыть рабочий стол

Файл:

```text
Home.md
```

Показывает:

- статистику сроков;
- быстрые ссылки;
- активные дедлайны;
- предметы;
- кнопки создания заметки и обновления расписания.

### 2. Создать новую заметку

Шаблон:

```text
50-Система/Шаблоны/Новая заметка.md
```

Создание идёт через Templater.

### 3. Смотреть дедлайны

Файл:

```text
50-Система/Дашборды/Дедлайны.md
```

Использует `due_date` и `status` из frontmatter.

### 4. Смотреть предмет

Каждый предмет имеет MOC:

```text
10-Университет/<Предмет>/MOC — <Предмет>.md
```

MOC собирает заметки из папки предмета через DataviewJS.

### 5. Обновить расписание

Расписание обновляется из Obsidian Desktop через кастомный плагин:

```text
.obsidian/plugins/sirius-schedule/main.js
```

Плагин запускает:

```text
sirius-update.py
```

и затем автоматически перечитывает:

```text
sirius-schedule.json
```

Команда полной загрузки:

```text
sirius-schedule:sirius-update-from-site
```

## Критичные зависимости

Community plugins:

- Dataview
- Templater
- Calendar
- Sirius Schedule custom plugin

Без Dataview большая часть функциональных страниц не работает.
Без Templater не работает кнопка создания новой заметки.

## Функциональные страницы

Функциональные страницы — это страницы, которые являются интерфейсом системы, а не учебным содержанием.

Примеры:

- `Home.md`
- `Дедлайны.md`
- `MOC — *.md`
- `Проекты.md`
- `Личное.md`
- системные индексы
- отчёты

Все такие страницы должны иметь:

```yaml
---
cssclasses:
  - university-dashboard
---
```

## Данные заметок

Основные поля frontmatter:

```yaml
title: Название
type: ДЗ
subject: Математика
project: ""
tags: университет/математика/дз
due_date: 2026-06-01
priority: medium
status: В работе
```

Типы:

- `ДЗ`
- `Лекция`
- `Конспект`
- `Проект`
- `Лаба`
- `Экзамен`
- `Источник`
- `Разное`

Статусы:

- `Идея`
- `В работе`
- `На проверке`
- `Готово`

Приоритеты:

- `low`
- `medium`
- `high`

## Текущие известные предупреждения

Скрипт health-check может находить чувствительные слова в ПИД-документах. Это не обязательно утечка — часто это часть UX/user-story текстов. Но при публичной публикации такие места стоит просматривать вручную.

## Как правильно завершать задачу

В конце работы AI должен сообщить:

1. Что изменено.
2. Какие файлы затронуты.
3. Какие проверки запущены.
4. Что пользователь должен проверить вручную в Obsidian.
5. Какие риски или ограничения остались.
