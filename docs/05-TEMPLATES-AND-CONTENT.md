# 05 — Templates and content model

Это главный документ про шаблоны, frontmatter, типы заметок и MOC.

## Центральный файл

Источник логики новых заметок:

- `50-Система/Шаблоны/Новая заметка.md`

## Что делает шаблон

Шаблон:
- спрашивает предмет;
- спрашивает тип заметки;
- спрашивает тему;
- при необходимости просит дедлайн, статус и приоритет;
- формирует путь до нужной папки;
- создаёт MOC, если его ещё нет;
- формирует YAML;
- перемещает заметку в нужное место;
- заполняет стандартную структуру заметки.

## Основные поля заметки

| Поле | Значение |
|---|---|
| `title` | имя заметки |
| `type` | тип материала |
| `subject` | предмет |
| `project` | название проекта, если тип = Проект |
| `tags` | иерархические теги |
| `created` | дата создания |
| `due_date` | дедлайн |
| `priority` | приоритет |
| `status` | статус |
| `cssclasses` | классы оформления |

## Какие типы заметок есть

По умолчанию:
- Проект
- ДЗ
- Лекция
- Конспект
- Лаба
- Экзамен
- Источник
- Разное

## Какие типы требуют дедлайн

По умолчанию дедлайн ожидается у:
- Проект
- ДЗ
- Лаба
- Экзамен

Если хочешь это изменить — меняй массив `ТИПЫ_С_ДЕДЛАЙНОМ`.

## Как определяется папка

В шаблоне есть два уровня маршрутизации:

1. Базовый путь:
- `10-Университет/<предмет>`
- `20-Проекты/IT`
- `30-Личное`

2. Подпапка по типу:
- `ДЗ`
- `Лекции`
- `Конспекты`
- `Лабораторные`
- `Экзамены`
- `Источники`
- `Проекты/Проект <Тема>`
- `Разное`

## Как устроены обычные заметки

Сейчас обычные учебные заметки создаются в стабильном формате через callout-блоки:
- `meta-card`
- `notes-card`
- `links-card`
- `result-card`

Их стиль задаётся в `university-dashboard-v5.css`.

## Что такое MOC

`MOC — <Предмет>.md` — это предметная обзорная страница.

Она:
- собирает заметки по предмету;
- группирует их;
- показывает статусы и дедлайны;
- даёт поиск внутри предмета.

## Важно про source of truth

Если хочешь изменить **все новые заметки**, меняй шаблон.

Если хочешь изменить **только уже созданные заметки**, нужно либо:
- переписать их вручную;
- либо написать миграцию/массовое преобразование.

## Когда нужно менять шаблон обязательно

| Ситуация | Менять шаблон? |
|---|---|
| Добавил новый тип заметки | да |
| Добавил новый предмет | да |
| Изменил YAML-поля | да |
| Изменил структуру тела заметки | да |
| Изменил правила дедлайнов | да |

## Что ещё связано с шаблоном

После изменения шаблона часто нужно проверить:
- `Home.md`
- `Дедлайны.md`
- MOC-страницы
- `auto-note-mover` config

Потому что эти части читают те же поля и теги.
