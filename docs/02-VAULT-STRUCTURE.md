# 02 — Vault structure

Ниже — логика структуры проекта. Это не случайный набор файлов, а vault, разделённый на контент и систему.

## Верхний уровень

| Путь | Назначение |
|---|---|
| `00-Inbox/` | Входящая корзина / черновики |
| `10-Университет/` | Учебные материалы по предметам |
| `20-Проекты/` | Проектные заметки |
| `30-Личное/` | Личные заметки |
| `40-Знания/` | База знаний |
| `50-Система/` | Системные дашборды, шаблоны и служебные заметки |
| `99-Архив/` | Архив старых, промежуточных и неактуальных материалов |
| `.obsidian/` | Настройки Obsidian, plugins, snippets |
| `docs/` | Документация по проекту |

## Контентный слой

### `10-Университет/`

Здесь лежат предметы:
- Английский
- Биология
- ВВС
- География
- Другое
- Информатика
- История
- Литература
- Математика
- ОП
- Обществознание
- ПИД
- Русский
- Физра

Внутри предметов обычно есть подпапки:
- `ДЗ`
- `Лекции`
- `Конспекты`
- `Лабораторные`
- `Проекты`
- `Экзамены`
- `Источники`
- `Разное`

Также почти у каждого предмета есть `MOC — <Предмет>.md`.

### `20-Проекты/`

Для отдельных проектных заметок. Сейчас используется как отдельный самостоятельный раздел с обзорной страницей `Проекты.md`.

### `30-Личное/`

Личный раздел. Та же идея, что и у `20-Проекты`, но для личных материалов.

## Системный слой

### `50-Система/Дашборды/`

Здесь лежат страницы-дашборды.

Главное:
- `50-Система/Дашборды/Дедлайны.md`

### `50-Система/Шаблоны/`

Здесь лежат шаблоны Templater.

Главное:
- `50-Система/Шаблоны/Новая заметка.md`

## Файлы в корне

| Файл | Роль |
|---|---|
| `Home.md` | Главная панель проекта |
| `START_HERE.md` | Точка входа для нового человека |
| `01-07_*.md` | Аналитические документы проекта |
| `sirius-update.py` | Внешний Python-скрипт обновления расписания |
| `sirius-schedule.json` | Сырые данные расписания |

## Что считается сгенерированным или служебным

| Что | Статус |
|---|---|
| `_Index_of_*.md` | служебные индексы |
| `.makemd/*` | служебные файлы Make.md |
| `sirius-schedule.json` | данные, генерируемые/обновляемые системой |
| `.obsidian/plugins/*/main.js` | код сторонних плагинов |

## Как мыслить структуру

Если коротко:

- **Контент** лежит в `10/20/30/40`
- **Система** живёт в `50-Система` и `.obsidian`
- **Главный стиль** лежит в `.obsidian/snippets`
- **Главная логика новых заметок** лежит в шаблоне Templater
- **Главная точка входа пользователя** — `Home.md`
