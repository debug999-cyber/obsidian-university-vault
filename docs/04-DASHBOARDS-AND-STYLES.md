# 04 — Dashboards and styles

Этот документ объясняет, как устроены дашборды и внешний вид проекта.

## Главный файл дизайна

Главный источник UI:

- `.obsidian/snippets/university-dashboard-v5.css`

В этом файле находятся:
- design tokens;
- цвета;
- типографика;
- карточки;
- быстрые ссылки;
- стили заметок;
- стили document-note и university-note.

## Что находится в CSS

### Токены

Вверху файла хранятся:
- `--ud-*` переменные;
- палитра light/dark;
- тени;
- радиусы;
- скорости анимаций.

Если хочешь быстро изменить стиль проекта, начинай именно оттуда.

### Компоненты

В CSS уже описаны:
- top bar;
- hero;
- quick cards;
- search;
- task cards;
- subject cards;
- stat cards;
- callout-блоки для заметок;
- document-note стили для документации.

## Как работает `Home.md`

`Home.md` — это DataviewJS-страница. Она:
- собирает заметки с дедлайнами;
- считает активные задачи;
- строит карточки разделов;
- строит блок предметов;
- создаёт поиск по нескольким группам элементов;
- вызывает Templater для новой заметки;
- вызывает команду обновления расписания.

### Что важно внутри `Home.md`

| Блок | За что отвечает |
|---|---|
| `SUBJECT_ICONS` | иконки предметов |
| `folderPages()` | какие заметки попадают в разделы |
| `deadlineTone()` | как окрашиваются дедлайны |
| `quickCards` | быстрые карточки на главном экране |
| `applySearch()` | логика фильтрации |

## Local theme на Home

В `Home.md` реализован локальный переключатель темы панели.

Он использует ключ localStorage:
- `ud-shell-theme`

Это значит:
- переключение влияет на сам dashboard;
- системная тема Obsidian не обязательно жёстко диктует вид панели.

## Что менять, если нужен другой стиль

### Лёгкий рестайл
Меняй только переменные `--ud-*`.

### Средний рестайл
Меняй классы компонентов:
- `.ud-quick-card`
- `.ud-task-card`
- `.ud-subject-card`
- `.ud-search`
- `.ud-note-hero`
- `.callout[data-callout="..."]`

### Полная переработка layout
Тогда менять нужно уже и CSS, и DataviewJS-структуру страниц:
- `Home.md`
- `Дедлайны.md`
- обзорные разделы
- MOC-файлы

## Главное правило

Если меняешь **вид**, сначала меняй CSS.

Если меняешь **логику**, сначала меняй DataviewJS в соответствующей странице.
