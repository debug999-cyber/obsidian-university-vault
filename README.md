# Университетская база знаний (Obsidian)

![Obsidian](https://img.shields.io/badge/Obsidian-vault-6C6C77?style=flat-square&labelColor=1B1B14)
![Тема](https://img.shields.io/badge/для-учёбы-E0531A?style=flat-square)

> Хранилище для учёбы в **Obsidian**: конспекты, сводки и материалы для самопроверки
> в одном месте.

## Что внутри

| Раздел | Что это |
| --- | --- |
| **База знаний** | конспекты и материалы по предметам |
| **Дашборды** | сводки на Dataview |
| **Тесты** | заметки для подготовки и самопроверки |
| **Плагины** | Dataview, Tasks, Calendar, Make.md и др. — уже в репозитории |

## Как открыть

```bash
git clone https://github.com/debug999-cyber/obsidian-university-vault.git
```
Затем в Obsidian: **Open folder as vault** и выбрать папку.
