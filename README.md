- `AGENTS.md`

- `docs/ROADMAP.md`

```bash
python 50-Система/Скрипты/vault-health-check.py
python docs/check-dataviewjs-syntax.py
```

Учебное хранилище Obsidian с единым рабочим столом, дедлайнами, MOC-страницами, шаблоном создания заметок и интеграцией расписания Sirius.

## Быстрый старт

1. Открой папку как vault в Obsidian.
2. Включи community plugins из `.obsidian/community-plugins.json`.
3. Включи CSS snippets:
   - `university-dashboard-v5.css`
   - `professional-dark-v5.css`
   - остальные сниппеты по желанию.
4. Открой `Home.md` — это главный рабочий стол.

## Основные страницы

- `Home.md` — единый рабочий стол.
- `50-Система/Дашборды/Дедлайны.md` — контроль сроков по `due_date`.
- `10-Университет/Университет.md` — навигация по предметам.
- `20-Проекты/Проекты.md` — навигация по проектам.
- `30-Личное/Личное.md` — личный раздел.
- `50-Система/Обновить связи MOC.md` — обслуживание MOC и ссылка на проверку vault.
- `50-Система/Отчёты/VAULT_HEALTH.md` — последний отчёт проверки.

## Frontmatter для учебных задач

Для дедлайнов используются поля:

```yaml
title: Название
type: ДЗ
subject: Математика
due_date: 2026-06-01
priority: medium
status: В работе
```

Поддерживаемые статусы:

- `В работе`
- `На проверке`
- `Идея`
- `Готово`

Заметки со статусом `Готово` попадают в выполненные.

## Создание новой заметки

Используется шаблон:

```text
50-Система/Шаблоны/Новая заметка.md
```

Создавать можно через кнопку `Новая заметка` на `Home.md` или напрямую через Templater.

## Расписание Sirius

Расписание обновляется автоматически через кастомный плагин:

```text
.obsidian/plugins/sirius-schedule/
```

Что теперь работает:

- кнопка `Скачать расписание` на `Home.md` запускает загрузку с сайта Sirius;
- команда Obsidian `Sirius Schedule: Обновить расписание с сайта Sirius` делает то же самое;
- при старте Obsidian расписание обновляется автоматически, если JSON старше заданного порога;
- после загрузки JSON перечитывается сам, руками запускать `python sirius-update.py` не нужно.

Первичная настройка в Obsidian:

1. Открой `Settings → Community plugins → Sirius Schedule`.
2. Укажи свою группу вместо `К0000-00/0`.
3. Проверь путь к Python: обычно `python`, `python3` или полный путь к `python.exe`.
4. Оставь `sirius-update.py` как путь к скрипту.

Скрипт `sirius-update.py` сам попытается установить недостающие зависимости и Chromium для Playwright при первом запуске. Если автоматическая установка отключена или не сработала, выполни вручную:

```bash
pip install -r requirements.txt
playwright install chromium
```

Ручной запуск всё ещё возможен, но больше не обязателен:

```bash
OBSIDIAN_VAULT="/path/to/vault" SIRIUS_GROUP="К0000-00/0" python sirius-update.py
```

## Проверка работоспособности

Запусти:

```bash
python 50-Система/Скрипты/vault-health-check.py
```

Скрипт проверяет:

- пустые Markdown-файлы;
- OS-мусор;
- битые wiki-ссылки;
- обязательные поля у заметок с `due_date`;
- валидность дат;
- возможные упоминания секретов/личных данных.

Результат сохраняется в:

```text
50-Система/Отчёты/VAULT_HEALTH.md
```

## Принцип дизайна

Все функциональные страницы используют один класс:

```yaml
cssclasses:
  - university-dashboard
```

Единый визуальный язык находится в:

```text
.obsidian/snippets/university-dashboard-v5.css
```

Обычные учебные заметки этим рефакторингом не затрагиваются.
